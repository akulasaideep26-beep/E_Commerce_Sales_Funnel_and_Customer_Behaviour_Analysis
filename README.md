# E-Commerce Sales Funnel & Customer Behaviour Analysis

## Project Overview
This project analyzes e-commerce customer behaviour and purchasing patterns using Python. It focuses on understanding sales funnel conversion, customer retention, product revenue, and hourly shopping activity.

## Dataset
- Source: E-Commerce Behaviour Data
- Period: October 2019 – February 2020
- Combined dataset: 20.69 million records before duplicate removal
- Cleaned dataset: 19.58 million records

## Objectives
- Analyze customer movement through the sales funnel.
- Identify customer retention patterns using cohort analysis.
- Calculate revenue generated by products and categories.
- Understand hourly customer behaviour through heatmap visualization.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Key Analysis
1. Sales Funnel Analysis
2. Customer Cohort and Retention Analysis
3. Product Revenue Analysis
4. Category Revenue Analysis
5. Hourly Customer Behaviour Heatmap
